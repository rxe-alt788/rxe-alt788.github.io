# Security

This repository publishes a static portfolio website. It should not contain credentials, API keys, access tokens, private personal information or production data.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Email **john@trinityco-ai.co** with:

- the affected page or file;
- a concise description of the issue;
- steps to reproduce it, where safe to do so.

Please allow time for review before publicly disclosing a vulnerability.

## Maintainer practices

- Keep credentials and private configuration outside the repository.
- Review changes before publishing to the default branch.
- Keep third-party dependencies to a minimum and use reputable sources.
- Treat all submitted content and external links as untrusted until reviewed.
