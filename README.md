# Trinity Collective
### Research · Technology · Change

The public portfolio for the work of John Dunn and Trinity Collective (Australia / UK).

**Live site:** https://rxe-alt788.github.io/

Trinity brings together public-interest tools, independent research and advisory practice. The common thread is practical: identify overlooked capability, understand the dependencies that shape a system, and turn that understanding into useful action.

The individual project repositories remain the source of truth for their code, technical documentation and release history. This repository is the portfolio and presentation layer.

## Working principles

- Be clear about what is built, what is being tested and what remains a research proposition.
- Keep project-specific code and technical documentation in their own repositories.
- Do not commit credentials, tokens, personal data or private operational material.
- Prefer traceable changes over direct, unreviewed edits to the published site.
